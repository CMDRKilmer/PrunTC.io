# 🚀 PrunTC - 船舱装载优化器

一个专为 Prosperous Universe 设计的船舱装载优化工具，包含两个核心功能：补给运输计算器（PrunTC）和最少次数运输计算器（MTC）。

## ✨ 功能特性

### 🎯 核心功能
- **补给运输计算器（PrunTC）**：基于库存平衡算法计算最优装载方案，最大化船舱利用率
- **最少次数运输计算器（MTC）**：计算将所有物品运完所需的最少运输次数，优化运输效率
- **智能容量适应**：当容量不足时，自动剔除库存天数最多的物品，确保计算顺利进行
- **智能优化算法**：基于二分查找和三阶段优化策略，快速找到最优解
- **多船舱支持**：8种标准船舱类型，一键切换容量配置
- **材料自动匹配**：376种材料数据库，输入代码自动填充重量/体积
- **实时计算**：即时显示装载方案、填充率和预计可用天数

### 🌐 FIO API 集成
- **一键登录**：支持用户名密码和 API 密钥两种认证方式
- **基地列表获取**：自动获取账户下所有基地信息
- **多基地选择**：支持同时选择多个基地进行数据汇总
- **数据自动加载**：自动获取各基地的生产数据、劳动力消耗和存储数据
- **工人消耗汇总**：自动计算并显示各基地的工人日常消耗品

### 🎨 界面特性
- **响应式设计**：适配桌面和移动设备
- **深色/浅色主题**：支持一键切换，自动保存偏好
- **玻璃拟态风格**：现代化UI设计
- **动画效果**：流畅的进度条和交互动画
- **统一界面**：两个计算器使用一致的界面风格

### 📊 数据展示
- **填充进度条**：直观显示重量/体积利用率
- **瓶颈分析**：自动识别限制因素
- **详细清单**：每个物品的装载数量、重量、体积
- **预计可用天数**：基于消耗率计算库存持续时间（仅PrunTC）
- **被剔除物品提示**：容量不足时清晰显示哪些物品被排除及原因
- **运输方案**：详细的运输次数和每次装载内容（仅MTC）

## 📖 使用指南

### PrunTC - 补给运输计算器

#### 方式一：手动输入
1. **选择船舱类型**
   - 从下拉菜单选择预设船舱类型
   - 或手动输入自定义载重和容积

2. **添加物品**
   - 输入物品代码（如 `DW` `RAT` `OVE`）
   - 系统自动匹配重量和体积
   - 输入现有库存和每日消耗量
   - 点击"添加物品"

3. **计算优化**
   - 点击"计算最优装载方案"
   - 查看填充进度和详细清单
   - 根据结果调整物品或容量

4. **管理物品**
   - 点击物品行删除单个物品
   - 使用"清空物品"移除所有
   - 使用"加载示例"快速体验

#### 方式二：FIO API 自动导入
1. **登录 FIO API**
   - 点击"🔑 登录"按钮
   - 选择认证方式（用户名密码或 API 密钥）
   - 输入凭据并登录

2. **选择基地**
   - 登录成功后显示基地列表
   - 勾选要导入数据的基地（支持多选）
   - 点击"📥 加载选中基地数据"

3. **自动计算**
   - 系统自动获取选中基地的生产数据和存储数据
   - 自动计算工人日常消耗品
   - 自动填充物品列表和数量
   - 点击"计算最优装载方案"获取结果

4. **查看被剔除物品（如有）**
   - 当容量不足时，系统会自动剔除库存天数最多的物品
   - 结果区域会显示橙色警告框，列出被剔除的物品
   - 显示物品代码、库存、消耗和库存天数信息

### MTC - 最少次数运输计算器

1. **选择船舱类型**
   - 从下拉菜单选择预设船舱类型
   - 或手动输入自定义载重和容积

2. **添加物品**
   - 输入物品代码（如 `INS` `MCG`）
   - 系统自动匹配重量和体积
   - 输入物品数量
   - 点击"添加物品"

3. **计算优化**
   - 点击"计算最少运输次数"
   - 查看运输次数和详细方案
   - 根据结果调整物品或容量

4. **管理物品**
   - 点击物品行删除单个物品
   - 使用"重置"移除所有
   - 使用"快速示例"加载预设数据

## 🧮 算法说明

### PrunTC 算法
- **核心规则**：库存平衡（所有物品补充后的库存天数相同）
- **智能容量适应**：容量不足时自动剔除库存天数最多的物品，确保计算顺利进行
- **优化策略**：二分查找快速收敛最优天数
- **性能指标**：平均 0.001ms/次计算

### MTC 算法
- **核心规则**：最少运输次数，最大化每趟利用率
- **三阶段优化策略**：
  1. **双极限组合查找**：寻找能同时填满重量和体积的物品组合
  2. **密度互补装载**：优先装载密度最大和最小的物品
  3. **剩余空间填充**：优化剩余空间的利用
- **智能评分**：综合考虑填充率、平衡度和连续性
